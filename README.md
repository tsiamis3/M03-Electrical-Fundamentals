# M03 Electrical Fundamentals — course site

Στατικό site για GitHub Pages: σημειώσεις κάθε μαθήματος, ασκήσεις ανά μάθημα και τράπεζα ερωτήσεων που μεγαλώνει μαζί με το μάθημα.

## Σελίδες

| Αρχείο | Τι κάνει |
| --- | --- |
| `index.html` | Το τελευταίο μάθημα, το lesson log και η εξάσκηση |
| `lessons.html` | Όλα τα 35 μαθήματα ομαδοποιημένα ανά ενότητα A–F + Τελική επανάληψη (τα planned φαίνονται αχνά) |
| `lesson.html?id=L01` | Σελίδα σημειώσεων (`lessons/L01.md`) και οι ασκήσεις του μαθήματος |
| `practice.html` | Φίλτρα ανά ενότητα (A–F), μάθημα, topic και δυσκολία, και quiz |
| `formulas.html`, `units.html`, `sims.html` | Τυπολόγιο, μονάδες με μετατροπέα, προσομοιώσεις |
| `review.html` | Για τον καθηγητή: approve / fix / retire ανά ερώτηση (δεν υπάρχει link στο μενού) |

## Ενότητες (κατηγορίες μαθημάτων)

Οι 6 ενότητες ορίζονται στο `UNITS` του `tools/make_lessons.py`:

| Ενότητα | Topics | Τίτλος |
| --- | --- | --- |
| A | 3.01–3.04 | Ηλεκτρόνια, φορτίο και πηγές |
| B | 3.05–3.08 | Πηγές και κυκλώματα DC |
| C | 3.09–3.11 | Χωρητικότητα, μαγνητισμός, αυτεπαγωγή |
| D | 3.12 | Μηχανές DC |
| E | 3.13, 3.14, 3.16 | Θεωρία και κυκλώματα AC |
| F | 3.15, 3.17, 3.18 | Μετασχηματιστές και μηχανές AC |
| R | όλη η ύλη | Τελική επανάληψη (mock exams) |

Κάθε μάθημα μπαίνει αυτόματα στην ενότητα του τελευταίου του topic (π.χ. το «Τεστ 1: ενότητες Α και Β» πάει στη B). Μάθημα που καλύπτει όλη την ύλη πάει στο R. Για αλλαγή τίτλου ή topics μιας ενότητας, άλλαξε το `UNITS` και τρέξε `python tools/make_lessons.py`.

## Συνοδευτικά σε βάθος

Στο `deep/Lxx.md` υπάρχει, για κάθε μάθημα, η φυσική πίσω από την ύλη με παραπομπές στον Jackson (3η έκδ.) και λυμένες ασκήσεις. Είναι για τον καθηγητή και δεν υπάρχει link τους στο site.

## Ροή μετά από κάθε μάθημα

1. Γράψε τις σημειώσεις στο `lessons/Lxx.md` (Markdown, με πίνακες, `<div class="formula">…</div>` για τύπους και `> …` για σημειώσεις στο περιθώριο).
2. Βάλε τις ασκήσεις στο `data/questions/Lxx.json`, με την ίδια μορφή όπως στο `L01.json`. Τα hints για λάθος απαντήσεις μπαίνουν στο `data/questions/_misc.json`.
3. Βάλε το `Lxx` στο `PUBLISHED` του `tools/make_lessons.py`.
4. Τρέξε:
   ```
   python tools/make_lessons.py
   python tools/build_bank.py
   ```
5. Κάνε commit και push. Το μάθημα ανοίγει στο site.

## Αξιολόγηση της τράπεζας

Κάθε ερώτηση έχει `status`: `new` → `approved`, ή `fix` (κρυφή μέχρι να διορθωθεί), ή `retired` (κρυφή μόνιμα).
Οι μαθητές βλέπουν μόνο τις `new` και `approved`.

1. Άνοιξε το `review.html` και σημείωσε τις αποφάσεις σου (μένουν στον browser).
2. Πάτα **Download review.json** και τρέξε `python tools/build_bank.py --review review.json`.
3. Οι αποφάσεις γράφονται στα `data/questions/*.json` και το `data/bank.js` ξαναχτίζεται.

## Τοπική δοκιμή

Οι σημειώσεις φορτώνονται με `fetch`, οπότε χρειάζεσαι server: `python -m http.server` και μετά άνοιξε το `http://localhost:8000`.

## Θέμα

Το `assets/lab.css` περιέχει το θέμα «εργαστήριο τρελοεπιστήμονα»: πλακάκια εργαστηρίου, πάνελ από βακελίτη με χάλκινη ακμή, σημειώσεις σε σελίδα τετραδίου και το τόξο Tesla στην κεφαλίδα. Το τόξο ξαναπετάει σπίθα όταν πατάς τον τίτλο. Τα χρώματα αλλάζουν από τις μεταβλητές στην αρχή του αρχείου.
Ο κοινός κώδικας (header, γλώσσα, τράπεζα, quiz) βρίσκεται στο `assets/core.js`. Τα links του μενού ρυθμίζονται στο `SITE.LINKS`.
